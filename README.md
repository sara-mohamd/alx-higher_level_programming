## Learning Objectives

### Python Fundamentals
- Variables, data types, and operators
- Control structures (if/else, loops)
- Functions and modules
- Error handling

### Object-Oriented Programming
- Classes and objects
- Inheritance and polymorphism
- Encapsulation and abstraction
- Magic methods and properties

### Advanced Topics
- Test-driven development with `unittest`
- File I/O and JSON serialization
- SQL databases and ORM (SQLAlchemy)
- Network programming (HTTP, APIs)

## Requirements

- Python 3.8+
- MySQL 8.0+ (for SQL projects)
- Node.js 14+ (for JavaScript projects)

## Usage

```bash
# Run Python scripts
python3 0x00-python-hello_world/script.py

# Run tests
python3 -m unittest discover tests/
```
